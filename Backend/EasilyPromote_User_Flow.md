# EasilyPromote – Business User Flow

## Flow Overview

```text
Auth
  ↓
Home
  ├── Create Campaign
  ├── Wallet
  └── Profile

(Home/Create Campaign)
        ↓
Create Campaign
        ↓
├── Set Up Campaign
├── Campaign Brief
└── Review & Launch
        ↓
View Campaign
        ↓
├── Overview
├── Submission
└── Payout
```

## Screen Descriptions

### 1. Auth
- User signs in or creates an account.

### 2. Home
Primary dashboard after authentication.
- Create Campaign
- Wallet
- Profile

### 3. Wallet
Manage campaign funds before launching campaigns.

### 4. Profile
Manage account and business information.

### 5. Create Campaign
Entry point into campaign creation.

### 6. Set Up Campaign
Configure campaign details.

### 7. Campaign Brief
Define objectives, requirements and creator instructions.

### 8. Review & Launch
Review campaign configuration before publishing.

### 9. View Campaign
Campaign management hub after launch.

Tabs:
- Overview
- Submission
- Payout

### Overview
Track campaign performance and metrics.

### Submission
Review creator submissions.

### Payout
Manage creator payments after verification.
